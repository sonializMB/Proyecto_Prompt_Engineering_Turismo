# Casos de estudio con modelos de lenguaje

Este repositorio contiene dos casos de estudio desarrollados con el propósito de explorar diferentes estrategias para el uso y adaptación de modelos de lenguaje de gran escala (LLM).

Los ejercicios se encuentran organizados en dos carpetas principales:

- **Fine-Tuning**
- **Prompt Engineering**

Cada caso de estudio incluye un notebook en el que se describe el procedimiento realizado, el código utilizado y los resultados obtenidos.

---

## 1. Caso de estudio: Fine-Tuning

Este caso de estudio consiste en el **entrenamiento y ajuste fino de un modelo de lenguaje Mistral-7B** con el propósito de responder preguntas relacionadas con el **Reglamento de Becas de la Universidad Autónoma de Tamaulipas (UAT)**.

El notebook muestra el proceso de preparación de los datos, configuración del modelo, entrenamiento mediante Fine-Tuning y evaluación de las respuestas generadas después del ajuste.

## 2. Caso de estudio: Prompt Engineering

Este caso de estudio aborda la aplicación de técnicas de **Prompt Engineering** para mejorar y controlar las respuestas generadas por un modelo de lenguaje.

El ejercicio está aplicado al dominio del **turismo**, utilizando información sobre atractivos turísticos y comparando los resultados obtenidos mediante diferentes formas de estructurar las instrucciones proporcionadas al modelo.
